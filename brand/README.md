# Macha face logo

- `macha-face.png` is a 1024 × 1024 transparent PNG for Google Auth Platform → Branding.
- `macha-face.svg` is the editable vector source.

The artwork recreates the existing warm-white rounded face and two dark eyes from the desktop icon, without the Windows shortcut arrow or app-name label. The Google-hosted account chooser supplies the Macha app name from Google Auth Platform branding settings.
